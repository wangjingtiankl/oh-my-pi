## [1.0.0] - 2026-04-01

### Added

- Initial release of `omp-docs` MCP server providing 15 knowledge query tools for extension development
- `omp_get_overview` — Extension system architecture overview with module diagram
- `omp_get_extension_guide` — Full extension development guide from `docs/extensions.md`
- `omp_get_hook_guide` — Hook development guide from `docs/hooks.md`
- `omp_get_custom_tool_guide` — Custom tool development guide from `docs/custom-tools.md`
- `omp_get_mcp_guide` — MCP server development guide from `docs/mcp-*.md`
- `omp_get_skill_guide` — Skill development guide from `docs/skills.md`
- `omp_get_api` — ExtensionAPI interface reference with method lookup
- `omp_get_events` — Event type definitions and handler signatures
- `omp_get_tool_schema` — ToolDefinition schema patterns with TypeBox examples
- `omp_list_examples` — List code examples by type (extension/hook/custom-tool/sdk)
- `omp_read_example` — Read example source code with metadata
- `omp_get_conventions` — Project development conventions from `AGENTS.md`
- `omp_list_docs` — List documentation files in `docs/`
- `omp_read_doc` — Read documentation file content
- `omp_search` — Search across docs, examples, and source types
- Runtime data loading from project files (no sync needed)
- stdio transport for local use only
